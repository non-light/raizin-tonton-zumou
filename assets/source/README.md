# 元画像

ゲームでは使いません。差し替えや作り直しのための原本です。
ゲームが読むのは `assets/characters/` にある軽量版です。

| ファイル | 中身 | ゲームでの使われ方 |
|---|---|---|
| `moriken-pressure.webp` | もりけんさん・金のオーラ（圧） | `moriken-pressure.png` の元 |
| `moriken-pressure-alt.webp` | 同じ構図の別案（黒背景・透過なし） | 未使用。差し替え候補 |
| `moriken-vortex.webp` | 黒い渦をためる | `moriken-vortex.png` の元 |
| `moriken-vortex-fire.webp` | 渦を撃つ | `moriken-vortex-fire.png` の元 |

PNGのままだと合計6.8MBあったため、解像度はそのままWebP(品質95)にして
1.5MBに落としてあります。等倍で見比べても違いは分かりません。

作り直すときは、元の高さを620pxにそろえて `assets/characters/` へ出します。
